# ClimaFuturo

Proyecto académico sobre estadísticas y pronósticos relacionados con el cambio climático.

## Páginas

- `index.html`: página de Inicio.
- `estadisticas.html`: visualización demostrativa de estadísticas.
- `pronosticos.html`: comparación demostrativa de escenarios.
- `css/styles.css`: hoja de estilos compartida.

## Cómo abrir el proyecto

1. Descargue y descomprima el archivo ZIP.
2. Abra la carpeta en Visual Studio Code.
3. Abra `index.html` en el navegador o utilice la extensión Live Server.
4. Verifique la navegación entre las tres páginas.

## Publicación en GitHub Pages

1. Cree un repositorio público en GitHub.
2. Suba los archivos conservando la carpeta `css`.
3. Ingrese a Settings > Pages.
4. Seleccione la rama principal y la carpeta raíz.
5. Guarde y espere a que GitHub genere el enlace público.

## Publicación en Netlify

1. Ingrese a Netlify.
2. Arrastre la carpeta descomprimida al área de publicación manual o conecte el repositorio de GitHub.
3. Espere a que Netlify genere el enlace público.
4. Compruebe las tres páginas y el funcionamiento del menú.

## Nota académica

Los valores y gráficas presentados son demostrativos. Antes de incorporar datos reales se deben verificar y citar las fuentes utilizadas.
