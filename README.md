# ClimaFuturo 

Proyecto académico sobre estadísticas y pronósticos climáticos.

## Funcionalidad JavaScript

La página `pronosticos.html` incluye un filtro por probabilidad de lluvia. El evento `change` del selector permite mostrar todos los días, los días con probabilidad alta (50 % o más) o los días con probabilidad baja (menos de 50 %). El resultado se actualiza sin recargar la página.

## Estructura

- `index.html`
- `estadisticas.html`
- `pronosticos.html`
- `css/styles.css`
- `js/script.js`

Microsoft Copilot se utilizó como apoyo para organizar, revisar e integrar la funcionalidad JavaScript. La publicación, comprobación y presentación del proyecto corresponden al responsable de la actividad.
